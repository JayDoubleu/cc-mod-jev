# cc-mod-jev

Claude Code mod (function-hook plugin) `jev-context`: Jev-scored context
pruning through OpenRouter. Read `README.md` for behaviour and configuration.

## Layout

- `.claude-plugin/plugin.json`: manifest and `userConfig` options.
- `.claude-plugin/marketplace.json`: single-plugin marketplace for `claude plugin marketplace add`.
- `hooks/hooks.json` and `hooks/jev-context.ts`: the hooks module (`session.compact`, `turn.complete`, `tool.call`, `command.run`, `session.start`).
- `src/`: the library, no imports outside the plugin. `compact.ts` orchestrates; `state.ts` builds and fits the Jev state; `questions.ts` phrases the `noul` questions; `apply.ts` rebuilds messages; `gate.ts` cuts oversized outputs; `openrouter.ts` is the client; `config.ts` resolves options and env overrides.
- `tests/`: `claude plugin test` suites. `library.test.ts` covers `src/`; `register.test.ts` drives the hooks through the engine `$` with a fake OpenRouter beneath.
- `evals/`: `claude plugin eval` cases.
- `scripts/smoke.ts`: one live compaction against OpenRouter. `scripts/gate-smoke.sh`: one headless session that checks the gate's cut note in the stream. `npm run smoke` runs both.
- `.claude/types/claude-code.d.ts`: generated by `/plugin-types` (Claude Code 2.1.278). Regenerate after an update; the other two generated files are ignored.

## Commands

- `npm run typecheck`, `npm run validate`, `npm test`, `npm run check` (all three).
- `npm run eval` needs `EVAL_OPENROUTER_API_KEY`. The without-arm costs model calls. A `tool.call` hook's `{ result }` is not applied inside eval children (2.1.278), so the gate is not evaluated there; use `scripts/gate-smoke.sh`.
- Every `claude` command that touches the mod needs `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`; the npm scripts set it.
- The OpenRouter key for local work lives in `.env` (gitignored). Never put it in a source file.

## Rules the hooks loader enforces

- Pass `$` only to functions declared at the top level of the hooks module.
- Call `$.env.get` with a literal name. A new option needs its two variables in `configOf` (the `Promise.all` list) and its key in `CONFIG_KEYS`.
- Every `$` call is spelled `$.noun.event(...)` at the call site.
- Hook code has a 10 s budget per dispatch; time spent inside `$.http.fetch` and `next(e)` does not count.
- `$.session.compact()` is refused from a `command.run` hook (it would compact under the turn the hook holds). Call it from `turn.complete`.
